# xtool — MCP Server

Exposes `xtool` iOS development commands as Model Context Protocol (MCP) tools for Claude Code, Claude Desktop, and other MCP clients.

## Features
- **Project Scaffolding**: Create SwiftPM-powered iOS apps.
- **Build & Dev Loop**: Compile and test iOS applications across platforms.
- **Device Management**: List devices, install IPAs, and launch applications.
- **Toolchain Status**: Verify Swift, Darwin SDK, and provisioning setup.
